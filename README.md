# Movies Finder

- Project for finding movies with [OMDB API](https://www.omdbapi.com)
- In project used:
  - React
  - React Router
  - React Hook Form
  - Tanstack Query
  - Intersection Observer (for infinite scroll)
  - Vite
  - SCSS
- ! Important: this project has fetch delay for showing loaders, Infinite Scroll Implementation and cashing data. You can turn it off in src/api/getMovies
